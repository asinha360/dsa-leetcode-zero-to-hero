# dsa-leetcode-zero-to-hero

A 20-week DSA / LeetCode curriculum for a non-technical beginner targeting
quant finance roles (quant developer, quant researcher, or SWE at a
trading firm or hedge fund). Solutions are written in C++ to compound a
parallel C++ quant finance curriculum. The pedagogy is pattern-first
recognition, deliberate practice, and spaced retrieval — not problem-count
grinding. Four milestones at W4 / W8 / W12 / W20 gate progression. Time
budget is 3–5 hrs/week; the C++ curriculum has unconditional priority and
this project pauses for any week the C++ track slips.

To use the workspace: open this directory in your editor, read
[CLAUDE.md](CLAUDE.md) (operating instructions for Claude),
[CONTEXT.md](CONTEXT.md) (project framing), and
[curriculum.md](curriculum.md) (the 20-week plan with weekly problem sets,
why-this-pattern reasoning, and acceptance tests). Each session follows the
weekly rhythm in `curriculum.md` (Day 1 intro / Day 2 solo / Day 3
retrieval / Day 4 review / Day 5 retrospective). Solutions go under
[solutions/weekXX/](solutions/), notes under [notes/](notes/) using the
`wX_dY.md` convention. End each session with `/sync` to commit and push.
Before starting, say `begin Week 1 Day 1` to begin the first session;
Claude will pick up from there.
