## Concepts introduced

### Why a window slides instead of restarts
- Restart cost: O(k) per subarray × (n−k+1) subarrays = O(n·k).
- Slide cost: O(k) once for first window + O(1) per slide × (n−k) slides = O(n).
- Calculus anchor: a sliding window is a discrete running integral. Add the new right endpoint's contribution, subtract the old left endpoint's. Never recompute from scratch.

### What property enables sliding
- Monotonicity with respect to boundary movement.
- When l advances past index i, index i is permanently eliminated — no future window can improve by including it.
- Same shape as two-pointer (W1): permanent discard based on a monotone argument.

### Fixed-length vs. variable-length windows
- **Fixed:** both boundaries move together; window size is rigid.
- **Variable:** expand r until constraint breaks; shrink l until restored.

### LC#121 (Best Time to Buy and Sell Stock) — traced on paper
- l = cheapest buy seen so far; r = current sell candidate.
- Shrink trigger: `prices[r] < prices[l]` → set `l = r` (new minimum at r's position).
- Bug surfaced: "move both right by 1" fails when l and r are non-adjacent — counterexample [3, 4, 5, 1, 6] (correct answer 5; buggy rule gives 2).
- Fix derived: `l = r`, not `l++`.
- Monotone property: every index to the left of l is a permanently suboptimal buy day; no future sell price can rescue it.
