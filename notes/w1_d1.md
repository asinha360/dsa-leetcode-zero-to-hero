## What we built (first principles chain)

1. **Array memory layout** — vector heap block is contiguous; control block on stack holds pointer + size + capacity. User knew this cold from C++ curriculum.
2. **O(1) random access** — `address[i] = base + i * sizeof(T)`. Fixed-cost arithmetic regardless of n. Derived from memory layout, not memorized.
3. **O(n²) brute force** — for each element x, scan the rest for `target - x`. n passes × O(n) scan = O(n²).
4. **Sorted order as information** — user identified that brute force discards the sorted property entirely.
5. **Elimination argument** — if `l + r < target`, everything left of r paired with l is also too small; advance l. If `l + r > target`, everything right of l paired with r is too large; advance r. User derived both halves independently.
6. **Two-pointer named and stated** — user restated the full algorithm unprompted, correctly.
7. **LC#125 constraint identified** — lowercase + strip non-alphanumeric. User identified two options (preprocess vs. in-place skip) and the O(n) extra space difference between them.
