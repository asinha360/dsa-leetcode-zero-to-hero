### LC#11 — Container With Most Water [M]
- **Pattern identified:** Two-pointer — "goal is to find two lines that contain most water; assign l=0, r=end; advance the shorter pointer"
- **Target complexity stated:** O(n) — "max visiting each element in array once"
- **Approach:** Two-pointer from both ends. Area = `min(height[l], height[r]) * (r - l)`. Move the shorter pointer inward at each step. Track running maximum. Insight self-derived via Socratic questioning — user identified "move the shorter pointer" and "moving the taller can only decrease area" without ladder hints.
- **Hints given:**
  - No ladder hints given. Claude restated the area formula after user's initial approach description was muddled — this was clarification of the problem setup, not a hint rung.
  - After coding: Claude identified the infinite-loop bug by asking "what happens when `height[l] == height[r]`?" — user self-corrected by adding `else { l++; }`.
- **LeetCode verdict:** Accepted — 65/65 cases passed, runtime beats 100% of C++ submissions (0 ms).
- **Final complexity:** O(n) time — l and r each move at most n steps total as they converge; O(1) space — three integer variables (l, r, maxArea). User stated time correctly unprompted. Space initially stated as "O(n)" — corrected to O(1) on one follow-up question. Classification: user-derived-with-correction (space only).
- **Code quality:** Duplicate `#include <vector>` (minor, no impact). `std::min` and `std::vector` used correctly. Variable naming clear. No off-by-ones. Equal-height case handled correctly in `else { l++; }` branch.
