## LC#15 — 3Sum [H]

**Complexity (user-derived):** O(n²) time; initially claimed O(1) space
**Time verdict:** Correct. O(n) outer × O(n) inner = O(n²), dominates O(n log n) sort.
**Space correction:** Output vector is **O(n²)** worst case, not O(1). Auxiliary space (excluding output) is O(log n) for `std::sort`'s introsort call stack. User conflated "no extra auxiliary allocation" with "constant output space." Corrected on first challenge.
**Code:**
- `i < nums.size()` — signed/unsigned comparison (`int` vs `size_t`). Correct fix: `i < static_cast<int>(nums.size())`. User proposed `static_cast<unsigned int>(i < (int)nums.size())` — this accidentally works (casts bool to unsigned int, 0 or 1), but is meaningless. Corrected.
- All three duplicate-suppression points are correct: outer (`i > 0 && nums[i] == nums[i-1]`), inner-l (`nums[l] == nums[l-1]` after match), inner-r (`nums[r] == nums[r+1]` after match).
- No logic bugs.
