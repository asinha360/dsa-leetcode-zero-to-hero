## LC#128 Longest Consecutive Sequence [H]

**Pattern:** Hash set + sequence-start detection.

**Pre-code statement:** O(n) time (hash set lookup O(1), each element counted forward at most once). O(n) space (set stores all n elements).

### Key insights arrived at during session

1. **Why not sort?** Sorting locks in O(n log n) floor — cannot reach O(n) target. Arrived without scaffolding after being asked to trace the complexity.

2. **Two-pass structure:** Build entire hashset first (full context), then detect starts. Order matters: checking during build would miss elements not yet inserted.

3. **Start detection:** `num - 1` not in set → num is a sequence start. Non-starts never trigger a forward count.

4. **Why O(n) total?** Each element is counted forward at most once across the entire run — it belongs to exactly one sequence, and only its sequence's start triggers the count. Total forward steps across all starts = n.

### Bugs encountered and resolved

1. `set.find()` used as bool — returns an iterator, always truthy. Fixed: use `set.contains()`.
2. `len = x` — initializes len to the element's value, not 1. For x=100, this checks set.contains(200) on first iteration. Fixed: `len = 1`.
3. `result = len` — overwrites previous result; loses longer sequences found earlier. Fixed: `result = std::max(len, result)`.
4. `return result` inside the for loop — returns after first iteration. Fixed: moved outside.
5. `else { continue; }` — dead code; loop continues automatically. Removed.
6. `auto it = set.find(x - 1)` inconsistent with `set.contains()` inside loop. Cleaned up to use `!set.contains(x - 1)` throughout.

**Verdict:** Accepted (85/85).

**Complexity verified:**
- Time: O(n) — each element pushed as start at most once, counted forward at most once. Total across all starts = n operations.
- Space: O(n) — set stores all n elements.

### Final solution

```cpp
class Solution {
public:
    int longestConsecutive(vector<int>& nums) {
        std::unordered_set<int> set(std::begin(nums), std::end(nums));
        int result = 0;

        for (const int& x : set) {
            if (!set.contains(x - 1)) {
                int len = 1;
                while (set.contains(x + len)) {
                    len++;
                }
                result = std::max(len, result);
            }
        }
        return result;
    }
};
```
