## LC#15 — 3Sum [H] — Accepted (316/316)

**Pattern:** Sort + outer fixed-element loop + inner two-pointer
**Target complexity:** O(n²) time, O(log n) auxiliary space

### Algorithm (plain English)
1. Sort the array — restores monotonicity so two-pointer can eliminate.
2. Outer loop: fix `nums[i]`. Skip if `nums[i] == nums[i-1]` (duplicate fixed element → duplicate triplets).
3. Inner two-pointer on subarray `[i+1 … n-1]`. Target = `-nums[i]`.
   - Sum too large → `r--`
   - Sum too small → `l++`
   - Sum exact → push triplet, `l++; r--`, then skip duplicate `l` and `r` values.

### Complexity derivation
- Sort: O(n log n)
- Outer loop: n iterations
- Inner loop: each pointer moves at most n times per outer iteration → O(n) per iteration
- Total: O(n) × O(n) = O(n²), dominates sort
- Auxiliary space: O(log n) for `std::sort` introsort stack

### Accepted solution
```cpp
class Solution {
public:
    vector<vector<int>> threeSum(vector<int>& nums) {
        std::sort(nums.begin(), nums.end());
        vector<vector<int>> triplets {};

        for (int i = 0; i < nums.size(); i++) {
            if (i > 0 && nums[i] == nums[i-1]) continue;

            int target = -(nums[i]); int l = i + 1; int r = nums.size() - 1;

            while (l < r) {
                if (nums[l] + nums[r] > target) {
                    r--;
                } else if (nums[l] + nums[r] < target) {
                    l++;
                } else {
                    triplets.push_back({nums[i], nums[l], nums[r]});
                    l++; r--;
                    while (l < r && nums[l] == nums[l-1]) l++;
                    while (l < r && nums[r] == nums[r+1]) r--;
                }
            }
        }
        return triplets;
    }
};
```

### Key insight built today
After sorting, fixing one element reduces 3Sum to 2Sum on a sorted subarray — a problem already solved. The hard part is duplicate suppression at three independent points: outer loop, l pointer, r pointer.
